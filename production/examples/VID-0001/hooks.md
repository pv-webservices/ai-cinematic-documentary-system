2. **Visual mystery:** “This corroded bronze fragment hid a machine for tracking the sky.” — CLM-002, CLM-004 — LOW.

4. **Counterintuitive:** “Long before mechanical clocks became common, this device used gears to model astronomical cycles.” — CLM-001, CLM-002 — MEDIUM; avoid unsupported comparative chronology in final unless separately sourced.
