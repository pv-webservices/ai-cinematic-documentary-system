# Fact-Check Workflow
1. Freeze the script version to review.
2. Verify every significant factual sentence has Claim IDs.
3. Compare wording against ledger status/confidence.
4. Re-open source evidence for disputed, causal, numerical, superlative and high-impact claims.
5. Flag unmapped facts and uncertainty upgrades.
6. Return PASS / PASS WITH CHANGES / FAIL.
7. Apply changes.
8. Rerun Fact Checker after any factual rewording.

`FAIL` blocks storyboard production.
