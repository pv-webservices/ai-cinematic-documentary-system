# Analytics Review Workflow
1. Export platform metrics after an appropriate observation window.
2. Record raw values without invented substitutes for unavailable fields.
3. Segment by topic, hook, duration, visual/narrative style where sample allows.
4. Look for repeated patterns, not single viral outliers.
5. Record confounders and sample size.
6. If evidence is actionable, create a learning entry and optionally an experiment.
7. Version affected Skill only when evidence/editorial need justifies change.
