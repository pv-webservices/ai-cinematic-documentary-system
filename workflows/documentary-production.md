# Phase 1 Documentary Production Workflow
1. Generate 10–20 topic ideas.
2. Score topics.
3. **Human selects topic.**
4. Generate research plan.
5. Collect sources.
6. Evaluate sources.
7. Build Claim Ledger.
8. Resolve important contradictions.
9. Create narrative angle.
10. Generate hooks.
11. **Human selects hook.**
12. Write documentary script.
13. Map claims to script.
14. Run Fact Checker.
15. Run Retention Optimizer.
16. **Human approves script.**
17. Build storyboard.
18. Perform visual research.
19. Generate image prompts.
20. Generate video prompts.
21. Generate narration.
22. Create sound design plan.
23. Produce assets.
24. Assemble video.
25. Run final QC.
26. **Human final approval.**
27. Publish manually.
28. Record analytics.
29. Perform postmortem after sufficient performance data exists.

No autonomous publishing in Phase 1.
