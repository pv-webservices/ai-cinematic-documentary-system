# Editorial & Correction Policy

## Core standard
Accuracy outranks speed, novelty and engagement. Real-person accusations, medical/scientific advice, current events and sensitive historical claims require stricter review than ordinary evergreen background material.

## Correction standard
If a published video contains a meaningful factual error:
1. log the issue and affected Claim IDs;
2. classify severity: minor, material, critical;
3. determine whether metadata/caption correction is sufficient;
4. replace/re-upload if the core narrative is materially wrong and correction is practical;
5. remove content if leaving it published would be materially misleading;
6. document root cause, source failure and Skill/workflow changes.

Never silently ignore a known factual error.

## Severity guide
- **Minor:** wording/precision issue that does not change the viewer's understanding.
- **Material:** changes interpretation, timeline, quantity, attribution or confidence.
- **Critical:** creates harmful, defamatory or fundamentally false understanding.
