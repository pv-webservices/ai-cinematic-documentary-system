# Naming Conventions

## IDs
- Topic: `TOPIC-0001`
- Video: `VID-0001`
- Claim: `CLM-001` (scoped to a topic/video research package)
- Source: `SRC-001`
- Experiment: `EXP-001`
- Visual: `VIS-001`
- Asset: `AST-001`

## Skill versions
`fact-checker-v1.0`, `documentary-writer-v1.1`, `storyboard-generator-v2.0`.

## Topic research package
`research/topic-briefs/TOPIC-0001/` may contain `brief.md`, `sources.md`, `claim-ledger.md`, `fact-check.md`, `visual-research.md`.

## Production package
`production/<stage>/VID-0001-*` or a self-contained package under `production/examples/VID-0001/` for demonstrations.

Use lowercase kebab-case for filenames, uppercase prefixes for IDs inside documents.
