# Platform Compliance

Before publishing, check the current YouTube/Instagram requirements for AI/synthetic content disclosures, misinformation, reused/repetitious content, copyright, harassment, dangerous content and monetization eligibility. Platform rules change; this file defines process, not permanent legal/platform facts.

Phase 1 checklist:
- 9:16 vertical framing for Shorts/Reels unless intentionally different;
- subtitles remain inside mobile safe areas;
- disclose materially realistic synthetic/reconstructed content when platform/user understanding requires it;
- avoid copied/reused content patterns;
- verify music/footage licenses;
- no autonomous publishing.
