# Citation Policy

Internal production files must preserve enough citation metadata for another reviewer to retrieve the evidence. Viewer-facing Shorts do not require on-screen academic citations for every sentence, but descriptions/captions may link key sources when appropriate.

## Minimum internal citation
`SRC ID | author/institution | title | publication/date | URL/DOI | access date | relevant pages/section if available`

Quote sparingly. Prefer paraphrase plus exact source location. Never invent a DOI, page number or quotation.
