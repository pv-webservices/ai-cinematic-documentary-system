# Originality Policy

Researching the same underlying topic as another creator is acceptable. Copying their execution is not.

Avoid script paraphrases, scene-by-scene recreation, distinctive sequence imitation, template spam and repeated factual structures with cosmetic changes.

Each production should create its own narrative angle, evidence synthesis, script, visual plan, pacing and conclusion. Competitor content can be analyzed for broad audience patterns, not reverse-engineered into near-copies.
