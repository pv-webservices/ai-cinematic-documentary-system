# Analytics Schema

Blank means unavailable/not yet measured; never substitute fabricated zeros. Rates should be recorded consistently as percentages or decimals across the dataset; choose one convention before first production and document it here.

- `video_id` — VID identifier.
- `platform` — youtube_shorts / instagram_reels / youtube_longform.
- `publish_date` — ISO date, YYYY-MM-DD.
- `title` — Published title/caption headline.
- `topic_id` — TOPIC identifier.
- `content_pillar` — Channel content pillar.
- `topic_category` — Science/history/etc.
- `hook_type` — Controlled hook taxonomy.
- `narrative_style` — Mystery/mechanism/cause-effect/etc.
- `duration_seconds` — Published duration in seconds.
- `visual_style` — Controlled visual taxonomy.
- `views` — Platform-reported views.
- `reach` — Unique/account reach where available.
- `impressions` — Platform-reported impressions where available.
- `three_second_views` — 3-second views where available.
- `three_second_retention` — 3-second retention rate where available.
- `scroll_away_rate` — Platform metric where available; leave blank otherwise.
- `average_watch_time` — Average watch time, seconds.
- `average_percentage_viewed` — Average % viewed.
- `completion_rate` — Completion rate where available.
- `replays` — Replay count/rate as recorded; note unit if platform varies.
- `likes` — Like count.
- `comments` — Comment count.
- `shares` — Share count.
- `saves` — Save count.
- `followers_gained` — Instagram followers attributed where available.
- `subscribers_gained` — YouTube subscribers attributed where available.
- `profile_visits` — Profile/channel visits where available.
- `traffic_sources` — Compact source summary or reference to export.
- `source_count` — Number of evaluated research sources used.
- `accuracy_corrections` — Count of documented published corrections.
- `accuracy_issues` — Short classification of known accuracy issues.
- `notes` — Confounders/context; never fabricate missing metrics.
