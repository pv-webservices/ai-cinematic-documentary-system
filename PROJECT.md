# PROJECT — Source of Truth

## Mission
Build a scalable AI-first documentary production system capable of turning credible research into original, visually compelling, understandable, and engaging educational videos.

## Editorial promise
The viewer should receive a clear, compelling explanation whose factual confidence matches the evidence. Mystery may motivate the story; it must never be manufactured by hiding decisive evidence or presenting speculation as fact.

## Core priorities
1. Factual accuracy
2. Strong storytelling
3. Audience retention
4. Visual quality
5. Originality
6. Production efficiency
7. Automation

## Initial positioning
Phase 1 prioritizes **Science + History + Mysteries** with evergreen topics. Avoid broad random-trivia publishing and breaking news until the sourcing/review system is proven.

## Content test
A topic should normally satisfy all of these:
- central question or explanatory tension;
- credible Tier 1/Tier 2 sources;
- meaningful narrative progression;
- strong visual or diagrammatic opportunities;
- clear viewer takeaway;
- manageable uncertainty for the chosen duration.

## Mandatory provenance chain
`TOPIC → SRC IDs → CLM IDs → script sentences → storyboard scenes → QC → VID analytics → Skill version change`

## Phase 1 non-goals
- autonomous publishing;
- unattended research-to-video generation;
- engagement optimization that overrides uncertainty;
- provider lock-in;
- paid API dependencies unless required for basic development;
- synthetic reconstructions presented as evidence.

## Development phases
### Phase 1 — Editorial Validation
Build 20–50 initial videos as a practical validation window. Human topic, script and final publishing approval remain mandatory.

### Phase 2 — Assisted Research and Production
Automate organization, claim extraction, prompt generation, metadata and repetitive file handling while preserving editorial review.

### Phase 3 — Production Automation
Automate source ingestion, claim tracking, storyboard and asset generation, narration, composition and analytics collection, with human final approval.

### Phase 4 — Shorts + Long-Form Ecosystem
Use successful Shorts and durable research packages to identify 3–5 and 6–10 minute opportunities. Long form requires additional research rather than filler.

### Phase 5 — Performance Feedback
Use comparable historical data to improve topic selection, hooks, pacing, duration, visuals and titles without weakening factual standards.

## Success metrics
Track platform performance plus research quality: views, reach, impressions, 3-second retention, scroll-away rate where available, watch time, average percentage viewed, completion, replays, engagement, follows/subscribers, traffic sources, duration, hook, topic, narrative style, visual style, source count, correction count and accuracy issues.

No benchmark is assumed in advance. Channel-level thresholds must be learned from the channel's own data.

## Decision rule
If a retention tactic conflicts with factual accuracy, remove the tactic. If a visual reconstruction cannot be made plausibly, switch to a diagram, map, label, archival/public-domain evidence, or explicit hypothetical visualization.
