# GitHub Bootstrap

The repository contents are complete and Git-ready. If the remote repository does not yet exist, create an empty GitHub repository named `ai-cinematic-documentary-system`, then from the extracted project directory run:

```bash
git init
git add .
git commit -m "chore: establish research-first documentary system foundation"
git branch -M main
git remote add origin https://github.com/<owner>/ai-cinematic-documentary-system.git
git push -u origin main
```

Do not copy a real `.env` file or credentials into the repository. The committed `.env.example` contains placeholders only.
